# スクワット動画の撮影ガイド（研究協力のお願い）

スマホの動画から、スクワットの「きつさ（RPE）」を推定する研究です。
**いつものトレーニングのメインセットを、スマホで撮って送るだけ**です（1回あたり +5 分くらい）。

---

## 1. 初回だけ

共有フォルダ（Google Drive）の **自分の名前のフォルダ** に `プロフィール.txt` を作って、次の4行を書いてください。

```
身長 175
体重 80
1RM 150
歴 5
```

- 1RM はスクワットの最大重量（kg）。**推定でOK**
- 歴 はトレーニング歴（年）

## 2. 撮り方（毎回同じに）

| | |
|---|---|
| 向き | **正面**（バーベルの真正面から） |
| 距離 | **2.5〜3 m** |
| 高さ | スマホを **腰の高さ**、**縦向き** |
| 画角 | **頭から足先まで全身**。しゃがんだときも、ラックから出るときも切れないように |
| 固定 | 三脚か台に立てかける（**手持ちはNG**） |
| 周り | 自分の前を人が横切らない位置 |
| 画質 | スマホの標準設定のままでOK |

**1セット = 1本**
録画開始 → ラックから外す → 挙げる → ラックに戻す → 録画停止

## 3. 撮るセット

- **メインセットは全部**（アップは撮らなくてOK）
- **3〜8回のセット**だと特にうれしい
- きつさがいろいろ混ざると最高です（RPE 6〜10）。**毎回限界までやる必要はありません。安全第一で**

## 4. RPE の付け方

**セットが終わったら 15 秒以内に決めて、後から変えない**でください。

| RPE | 意味 |
|---|---|
| 10 | もう1回も無理（限界） |
| 9 | あと1回できた |
| 8 | あと2回できた |
| 7 | あと3回できた |
| 6 | あと4回以上できた |

- 9.5、8.5 などの中間もOK
- 途中で潰れたセットは、**挙がった回数**を書いて RPE 10

## 5. 送り方

共有フォルダの自分のフォルダの中に **日付のフォルダ**（例: `20261005`）を作って、その日の動画を入れてください。
**Google Drive アプリからアップロード**してください（LINE で送ると画質と撮影時刻が消えるのでNG）。

重量・回数・RPE は **どちらか一方** で教えてください。

**A. ファイル名を変える**

```
100kg_5rep_RPE8.mp4
102.5kg_3rep_RPE9.5.mov
```

**B. メモを置く**（ファイル名はそのままでOK）

日付フォルダに `記録.txt` を作って、**撮った順に1行1セット**「重量 回数 RPE」

```
100 5 8
102.5 3 9.5
105 2 9
```

フォルダの例:

```
スクワット研究/
└─ 自分の名前/
    ├─ プロフィール.txt
    ├─ 20261005/
    │   ├─ IMG_1234.MOV
    │   ├─ IMG_1235.MOV
    │   └─ 記録.txt
    └─ 20261008/
        ├─ 100kg_5rep_RPE8.mp4
        └─ 105kg_3rep_RPE9.mp4
```
