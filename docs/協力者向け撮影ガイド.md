# スクワット動画の撮影ガイド（研究協力のお願い）

スマホの動画から、スクワットの「きつさ（RPE）」を推定する研究です。
**いつものトレーニングのメインセットを、スマホで撮って LINE で送るだけ**です（1回あたり +5 分くらい）。

---

## 1. 初回だけ

LINE で、次の4行を送ってください。

```
身長 175
体重 80
1RM 150
歴 5
```

- 1RM はスクワットの最大重量（kg）。**推定でOK**
- 歴 はトレーニング歴（年）

## 2. 撮り方（毎回同じに）

| | |
|---|---|
| 向き | **正面**（バーベルの真正面から） |
| 距離 | **2.5〜3 m** |
| 高さ | スマホを **腰の高さ**、**縦向き** |
| 画角 | **頭から足先まで全身**。しゃがんだときも、ラックから出るときも切れないように |
| 固定 | 三脚か台に立てかける（**手持ちはNG**） |
| 周り | 自分の前を人が横切らない位置 |
| 画質 | スマホの標準設定のままでOK |

**1セット = 1本**
録画開始 → ラックから外す → 挙げる → ラックに戻す → 録画停止

## 3. 撮るセット

- **メインセットは全部**（アップは撮らなくてOK）
- **3〜8回のセット**だと特にうれしい
- きつさがいろいろ混ざると最高です（RPE 6〜10）。**毎回限界までやる必要はありません。安全第一で**

## 4. RPE の付け方

**セットが終わったら 15 秒以内に決めて、後から変えない**でください。

| RPE | 意味 |
|---|---|
| 10 | もう1回も無理（限界） |
| 9 | あと1回できた |
| 8 | あと2回できた |
| 7 | あと3回できた |
| 6 | あと4回以上できた |

- 9.5、8.5 などの中間もOK
- 途中で潰れたセットは、**挙がった回数**を書いて RPE 10

## 5. 送り方（LINE）

その日のうちに、**撮った順に 1 本ずつ**送ってください。
**動画を 1 本送ったら、すぐ続けて 1 行**で「重量 回数 RPE」を送ります。

```
［動画］
100kg 5回 RPE8
［動画］
105kg 5回 RPE9
［動画］
110kg 5回 RPE9.5
```

- 動画は **切らずにそのまま**（録画開始〜録画停止まで）
- **1 本ごとに必ず 1 行**。順番を入れ替えない
- 撮った日より後に送るときは、先に「11/5 の分」のように撮った日を 1 行
- 重量や回数を書き間違えたら、何本目かを書いて直してください（RPE は後から変えない）

---

動画は研究のためだけに使い、外部には公開しません（骨格の座標データに変換して解析します）。
わからないことがあれば LINE で気軽に聞いてください。ご協力ありがとうございます！
