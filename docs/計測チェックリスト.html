1. 持ち物

  • M5StickC Plus（満充電・ファーム v4。Wi-Fi で送り続けると 30〜60 分しかもたない）＋ 固定用バンド
  • ノート PC（充電済み）
  • スマホ ＋ 三脚
  • テザリング（2.4 GHz）
  • 養生テープ（三脚の位置の目印）

2. セットアップ

  • テザリング ON → PC を接続
  • python scripts\multi_imu_receiver.py → 「重量 回数」を入れる（例 90 8）
  • M5 の電源 ON → 画面が「PC:… A」（緑）になる
  • M5 はバーの端（プレートの外側・動画で右側＝自分の左）。画面が真上、毎回同じ位置
  • バーを水平にして az ≈ +1.0 g −1.0 なら裏返す／0 付近なら 90° 回す。ここを外すと全部使えない
  • カメラ：バーベルの真正面・2.5〜3 m・腰の高さ・縦向き・三脚
  • 頭から足先まで全身が入る（しゃがんでも、ラックから出ても切れない） 足先が切れると、そのセットの動画は学習に使えない
  • 三脚の脚の位置に養生テープで目印

3. 各セット（繰り返し）

  1. 重さを付ける（重量・回数が変わるときは、グラフ画面で w → ターミナルで入力）
  2. スマホの録画開始
  3. PC で SPACE（セット開始）
  4. ラックアウト → 挙上 → ラックイン
  5. PC で SPACE（セット終了）
  6. RPE を声に出す（速度を見る前・15 秒以内・後から変えない）
  7. 数字キー　5〜9 ／ 0 ＝ RPE 10
  8. 録画停止
  • 撮った順がそのままセット番号（1 セット＝動画 1 本）
  • 1 日の中は回数を固定し、重さで RPE を変える（RPE 6〜10 に散らす）
  • 失敗するまで挙げない
  • 押し間違えたら u で取り消し

4. 横から撮るセット（IMU の確認用・アップでよい）

  • 受信を別のフォルダで起動 python scripts\multi_imu_receiver.py --outdir data\_side 忘れたら、帰宅後にその受信フォルダを data\_sessions から data\_side へ移す
  • 重さは 60 kg か 100 kg（いちばん外側が 20 kg プレート＝直径 45 cm） 40 kg など外側が小さいプレートは直径が分からず、比べられない
  • スマホは三脚で M5 側（自分の左）の真横。プレートがまん丸に見える位置・腰の高さ・縦向き
  • プレートが画面の幅の 1/3 くらいに写る距離。上から下まで切れない・ラックやセーフティで隠れない（最初の 1 本で確認）
  • 本番と同じく、回と回の間は立って 2 秒ほど止まる 本番と同じ条件で比べるため（11/6 の 60 kg は 0.6 秒だった）
  • RPE は入れない。録画開始 → SPACE → ラックアウト → 挙上 → ラックイン → SPACE → 録画停止
  • 合計 6 セット（できれば 2 日に分けて 3 セットずつ）。終わったら q → 本番の受信を起動

5. 終わったら（その場で）

  • q で終了（q で終えないと markers.csv が出ない）
  • mean Hz が 90〜100
  • セット数と動画の本数が同じ
  • RPE の入れ忘れがない
  • 記録ログに記入（睡眠・体重・体調・前回からの間隔）

6. 帰宅後

  • 動画を切るときは、1 回目の前と最後の後に 1 秒ずつ立っている時間を残す
  • 動画を data\_sessions\session_…\ の直下へ（受信を何回か起動した日は、フォルダごとにそのセットの動画。横から撮った分は data\_side\session_…\）
  • python scripts\run_pipeline.py → 最後の品質レポートで「要確認」を見る [待ち] と出たら、そのフォルダに動画が入っていない
  • 横から撮った日は python scripts\compare_side_imu.py

7. うまくいかないとき

M5 の PC: が黄色のまま受信スクリプトが動いているか／Windows ファイアウォールで Python を許可
az が 1.0 にならないM5 の画面が真上を向いているか
mean Hz が 50 未満Wi-Fi が弱い。PC をラックに近づける
足元が画面から切れる三脚を離す、または低くする
正面から撮れていないカメラをバーベルの真正面へ
横の動画でプレートを見つけ損ねたdata\_side\session_…\plate\*_bar_roi_preview.png の緑の円がプレートの縁に重なっているか。小さいプレート・ラックで隠れていないか
