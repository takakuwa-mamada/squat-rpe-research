# Weekly Research Progress

**Week:** YYYY-MM-DD

このIssueは前週金曜日に自動作成され、月曜日に今週の目標を設定し、金曜日に成果と課題を振り返るための週次記録です。

実際の研究作業は先に個別Issueを作り、このWeeklyにはIssue番号と「今週金曜日までの具体的な到達点」を書いてください。
Weeklyのチェック項目を後からIssueへ変換する運用は行いません。
詳細: https://github.com/YokoyamaLab/Lab_Management/blob/main/WORKFLOW.md

月曜の計画を記入したら、Projectの `Subject` を選択し、Statusを `In Progress` にしてください。

ゼミを欠席する場合も Friday Result は通常どおり更新してください。教員は同じIssue上で非同期レビューします。
