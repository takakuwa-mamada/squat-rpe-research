# バーベルスクワットの RPE（主観的運動強度）推定

アスリートがバーベル種目でよく使う指標 RPE（Rating of Perceived Exertion、「あと何回挙がるか」に基づく 1〜10 の強度）を、
**スマホの単眼動画から推定する**ための修士研究のコードです。

## 研究の概要

- **動画解析**: 正面から撮影した動画に YOLO26 Pose をかけ、肩の上下動から見たバー速度、テンポ、深さ、膝の内側への入り、
  横ブレ、左右の傾き、1レップ目から最終レップへの変化（疲労によるフォームの崩れ）を抽出する
- **IMU 計測（検証用）**: バーに付けた M5StickC Plus の加速度から挙上速度（MCV / MPV / 速度低下率）を求め、動画由来の速度を検証する基準にする
- **モデル**: 多人数のデータで汎用モデルを作り、本人のデータを足したときにどれだけ良くなるか（パーソナライズ）を評価する

## 構成

- `scripts/` 取り込み・骨格推定・特徴量抽出・評価（`run_pipeline.py` で一括、`train_rpe_model.py` で評価）
- `firmware/` M5StickC Plus の送信ファーム（Wi-Fi 設定を含むため .ino はリポジトリに入れていない）
- `docs/` 手順（`チートシート.txt`）、協力者向け撮影ガイド、研究の背景・設計判断（`研究コンテキスト.md`）
- 計測データ（`data/`）と解析結果（`outputs/`, `models/`）は個人データのためリポジトリに含めない

依存ライブラリ: `pip install -r requirements.txt`（動画の撮影日時の取得に ffmpeg の ffprobe を使う）
