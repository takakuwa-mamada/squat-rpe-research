# パワーリフティング スクワット RPE推定研究

パワーリフティングのスクワット挙上において、**動作データからRPE（主観的運動強度）を推定するモデル**を構築する研究です。

## 研究の概要

挙上のつらさ（RPE）を、選手の自己申告に頼らず客観的な動作データから推定できれば、トレーニング強度の管理や研究データの質を改善できます。本研究では以下のデータを組み合わせて特徴量を抽出し、RPE推定モデルを学習・評価します。

- **IMU計測**: バーベルシャフトや体幹・大腿などにセンサー（M5StickC Plus）を取り付け、加速度・角速度から挙上速度や姿勢角を算出
- **動画解析**: 側面から撮影した動画から骨格推定（関節角度・体幹傾き）とバーベルの軌道・速度を抽出
- **モデル学習**: これらの特徴量（挙上速度、関節角度、バー軌道など）からRPEを予測する機械学習モデルを構築・評価
