■ ジムで
-------------------------------------------------------------
 1. テザリングON → PC接続 → ipconfig でIP確認
 2. M5電源ON   → WiFi:OK / DSTがPCのIPと一致 / SEND
 3. python scripts\multi_imu_receiver.py
 4. バー水平で az ≒ 1.0 を確認   ★ここ外すと全部無駄
 5. 動画の録画を開始（セッション通して回しっぱなし）
 6. 各セット:
      SPACE → 挙上 → SPACE → RPEを声に出す → 数字キー
 7. q で終了 → mean Hz が 90〜100 か確認
 
 キー:  SPACE=セット区切り   6〜9=RPE   0=RPE10   5=RPE5
        u=直前を取消        q=終了

-------------------------------------------------------------
